# 📄 GitHub README.md Cheat Sheet

# Heading 1
```md
# Title
```

## Heading 2
```md
## Subtitle
```

### Heading 3
```md
### Small Heading
```

---

## Bold Text

```md
**Bold**
```

Output:

**Bold**

---

## Italic Text

```md
*Italic*
```

Output:

*Italic*

---

## Bold + Italic

```md
***Bold Italic***
```

Output:

***Bold Italic***

---

## Inline Code

```md
`print("Hello")`
```

Output:

`print("Hello")`

---

## Code Block

````md
```python
print("Hello")
````
## bullet list
